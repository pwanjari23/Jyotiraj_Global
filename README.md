# Jyotiraj Global Company

A premium, elegant, and minimal business showcase website for **JYOTIRAJ GLOBAL COMPANY** — Purveyors of premium dry fruits, artisanal confectionery, and prospective international trade partnerships.

## 🌟 Key Highlights

- **Brand-First Color System**: Custom palette tailored to the Jyotiraj logo (Warm Ivory `#FFFDF6`, Soft Cream `#F6F0E4`, Rich Brand Brown `#6D2D12`, Deep Roasted Brown `#3B1C12`, Golden Amber `#D99A16`, Leaf Green `#27843B`).
- **Dynamic Alternating Rhythm**: Alternating high-contrast light and dark sections that provide depth and visual luxury.
- **Dedicated Dry Fruit Photography**: Distinct, high-resolution photography for each individual dry fruit category (Almonds, Cashews, Pistachios, Walnuts, Raisins, Dates & Figs).
- **3D Cinematic Ladoo Showcase**: Pure food confectionery presentation on a luxury dark stone pedestal with floating gold shimmer particles and interactive 3D perspective tilt (zero human hands visible).
- **Global Trade & Business Section**: Professional import-export vision and B2B wholesale partnership details.
- **Direct Contact Integrations**: One-click WhatsApp direct chat, system email redirection, Gmail web shortcut, and live verified links to Instagram and Facebook.

## 🛠️ Technology Stack

- **React 19** with Functional Components and Hooks
- **Vite** for fast modern frontend tooling
- **Tailwind CSS v3** with custom theme tokens & responsive layouts
- **Lucide React** for clean minimalist iconography

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/pwanjari23/Jyotiraj_Global.git

# Navigate to project directory
cd Jyotiraj_Global

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

The application will run locally at `http://localhost:5173/`.

### Building for Production

```bash
npm run build
```

The production assets will be built in the `dist/` directory.
